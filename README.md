# Chang Yu — Personal Website

A responsive academic portfolio with restrained visual accents and light/dark themes for Chang Yu, an Economics and Electrical & Computer Engineering student at The Ohio State University.

## Content

- Undergraduate research with Prof. Alper Yilmaz in the Photogrammetric Computer Vision Lab, with links to the advisor and lab.

- Personal introduction, supplied portrait with CSS cropping, and email: yu.3594@osu.edu.
- **D²Mamba:** IEEE ISBI’27, under review. Chang Yu is first author (1/6).
- **EchoPE:** IEEE JBHI, under review. Chang Yu is fifth author (5/11).
- Complete author lists preserve manuscript order; first authors are bold.
- Authorship filters, research-detail dialogs, light/dark theme toggle, mobile layouts, and reduced-motion support.

Under-review manuscripts are not represented as accepted publications. Full manuscript PDFs are not included; the website contains summaries and figure excerpts supplied by the owner.

## Preview

```sh
python3 -m http.server 8765
```

Open http://localhost:8765/ . No package installation or build is required.

## GitHub Pages

Repository: https://github.com/PUREPANEL1/Personal_web

In **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/ (root)**. The expected project URL is https://purepanel1.github.io/Personal_web/ . All asset links are relative and work under the project path.

## Editing

- `index.html`: biography, paper titles, author lists, and statuses.
- `style.css`: visual design and responsive layout.
- `script.js`: paper details, filters, dialogs, and motion.
- `assets/`: supplied portrait, research figures, and favicon.
